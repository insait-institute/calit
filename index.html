Abstract

A Vision Transformer (ViT) is tasked to learn both a useful global representation through the CLS token and distinct local semantics through patch tokens. Yet a loss on the CLS token does not always induce learning of discriminative patch tokens. We theoretically observe that a CLS-based loss induces low rank patch gradients and in practice, most patches receive similar gradients. Adding patch-based losses may not compensate for the strong unidirectional CLS induced gradients. Consequently, even under global-local objectives, patch updates can remain insufficiently differentiated and spatially correlated. We therefore introduce cross-aggregation, which redefines the CLS token by aggregating patch-level concept heads in the expanded FFN space of every block. This parameter-free operation adds only 0.6% FLOPs to ViT-S and more directly couples global semantics to patch tokens. Combined with local depth-wise convolutions, it further improves the patch semantics, in a variety of pre-training methods. Together, these components form the Cross Aggregation and Local Mixing Transformer (CALiT). CALiT consistently improves semantic probes under both global-only and global-local pre-training objectives and vision-language finetuning. In particular, CALiT improves thin class semantics mean IoU by double digits in many pre-training/linear probe pairs and provides moderate gains in all other local semantics.

Method

CALiT changes only the FFN. After fc1 and GELU, each token's 4D-wide hidden is read as S slots of concepts, and two light modules act on it in parallel before fc2.

  • Cross Aggregation (CAg). The CLS slots attend over the slots of all patches: CLS slots are the queries, patch slots both the keys and the values, with as many heads as self-attention. There are no projection weights, so the operation is parameter-free and adds 0.6 % FLOPs to ViT-S. A loss on the CLS token now flows back to every patch through this softmax, besides the self-attention route.
  • Local Mixing (LMix). A 3×3 depthwise convolution over the patch hiddens on their √N×√N grid, one kernel per channel and no extra nonlinearity. It is Dirac-initialised, so at step 0 the block computes cross aggregation alone. A depthwise convolution alone, as in LocalViT, lowers the semantic probes on 3 of 4 datasets; added to CAg, it raises all four.
  • Cost. +0.75 % parameters and +1.44 % FLOPs for ViT-S, +0.40 % and +1.03 % for ViT-B. S = 4 slots for ViT-S and 8 for ViT-B (head size 64 and 32).
C′ = MHAH(C, P, P), heada = softmax  (CaP⊤a√dh) Pa
C ∈ ℝS×4D/S: the S slots of the CLS hidden. P ∈ ℝNS×4D/S: the S slots of each of the N patch hiddens. dh = 4D/(SH).
CALiT block, pseudocode 
# x: (1+N, D) tokens, CLS first, patches on a √N×√N grid.  S slots, H heads (as in SA).
y       = x + SA(LN(x))
h       = GELU(W1(LN(y)))              # (1+N, 4D)
h_c     = h[:1];  h_p = h[1:]          # split the CLS row from the N patch rows

# cross aggregation: parameter-free, MHA without projection weights
C       = h_c.reshape(S, 4D/S)         # CLS slots: queries
P       = h_p.reshape(N*S, 4D/S)       # patch slots: keys and values (un-mixed h_p)
h_c_new = MHA_H(C, P, P).reshape(1, 4D)

# local mixing: depthwise 3×3, Dirac-initialised, patches only
G       = h_p.T.reshape(4D, √N, √N)
h_p_new = DWConv3x3(G).reshape(4D, N).T

z       = y + W2(concat[h_c_new, h_p_new])
return z

Structure of the patch gradient at the input of the last block. Effective rank: entropy-effective rank of the 196×D gradient matrix; a plain ViT is bounded by 2nh (two routes per head). Gradient agreement, per model

  • ViT's patch gradients agree with the object direction inside and outside the box, and their effective rank stays at or below the 2nh bound (12 for S, 24 for B).
  • CALiT's effective rank is 2.6–3.6× ViT's, and its norm-weighted contrast is 1.6–2.6× higher, on 77–91 % of images.
  • In the supervised models the rank gap is there from epoch 100 and stays constant, while the contrast gap widens with training. Cross aggregation alone (CAT) already lifts the rank; local mixing adds contrast.
