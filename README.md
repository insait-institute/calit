# CALiT project page

Source of https://insait-institute.github.io/calit/, the project page for
**Vision Transformers Need Cross Aggregation for Patch Semantics** (CALiT, Cross Aggregation and Local Mixing Transformer).

Static HTML, one stylesheet and one small script; no build step and no external requests.

Preview locally:

```bash
python3 -m http.server 8000
```

then open http://localhost:8000.
